Урал-авто-2, в залежності від року виготовлення, може бути зібраний за різними схемами - на германієвих, або кремнієвих транзисторах. 
У даному випадку розглядається переробка версії 70-х років мин. ст. на германієвих транзисторах. 
Також вони мають значну відмінність саме за блоком УКХ. 
Гетеродин і змішувач були зібрані на мікросхемі К2ЖА242 (у більш нових версіях була К224ХА1 - це одне й те саме).

<b>Переробка</b>
<p>Було змінено вхідний ланцюг, замість германієвих транзисторів ГТ322A були встановлені кремнієві T1 - КТ3126Б, T2 - КТ3107Е.
